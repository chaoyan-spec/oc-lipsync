# OC 口播机

把 MP3、WAV 或 M4A 口播音频转换成可直接导入剪映的透明背景 OC 对嘴 MOV。现在使用 Memory Garden 的 8 帧说话素材，根据音量切换闭嘴、小张嘴、中张嘴，并在连续口播中加入自然闭合和眨眼。所有文件都只在本机处理，不会上传。

## PAPAlu 实时口型（macOS V1）

实时版用于录制屏幕教程：打开 PAPAlu 后，麦克风音量只在内存中驱动嘴型。明显讲话会立即张嘴，停止讲话约 120ms 后进入轻微待机动画；不会保存音频、上传数据或访问网络。待机只重新调度现有正式帧：大部分时间稳定闭嘴，间隔约 2.8～4.8 秒轻微呼吸，并在约 5.5～9 秒的随机间隔眨眼。重新讲话会立即取消待机行为，不增加口型响应延迟。

当前还包含一个摄像头动作最小实验：当摄像头检测到一只手在脸旁明显左右挥动时，PAPAlu 会临时显示约 0.8 秒的正式 `teaching` 状态，然后回到动作结束时最新的 talking / idle。摄像头画面不显示、不保存、不上传，只在内存中以约 12fps 分析人脸尺度和手部关键点。

### 构建与启动

电脑需要 Apple Command Line Tools。进入本项目后运行：

```bash
./realtime-macos/build-app.sh
open "outputs/PAPAlu实时口型.app"
```

生成位置是 `outputs/PAPAlu实时口型.app`。首次启动时允许麦克风和摄像头权限；如果之前拒绝，请到“系统设置 → 隐私与安全性”中的“麦克风”或“摄像头”重新打开。拒绝摄像头不会影响原有实时口型。直接拖动人物即可调整位置；使用 `Command +` 放大、`Command -` 缩小、`Command 0` 恢复默认大小，按 `Command-Q` 退出。

摄像头不会创建预览窗口。挥手时请让脸和至少一只正对镜头的手出现在画面内，并在脸旁连续左右摆动约 1～2 秒；本轮 `teaching` 只是挥手触发成功的单帧占位符，显示期间允许口型短暂停止。

运行实时逻辑与原生应用编译测试：

```bash
./realtime-macos/run-tests.sh
```

### 使用 QuickTime 录教程

1. 启动 `PAPAlu实时口型.app`，确认讲话时嘴型有反应。
2. 在 QuickTime Player 中选择“文件 → 新建屏幕录制”。
3. 选择麦克风。
4. 录制整个屏幕，或框选同时包含教程窗口和 PAPAlu 的区域。
5. 开始录制，结束后按普通视频流程剪辑。

PAPAlu 是独立悬浮窗口，因此不保证“只录制某一个应用窗口”时会被包含。请使用整个屏幕或选定区域。

## 开始使用

1. 双击 `启动OC口播机.command`；也可以在终端进入本目录后运行 `npm start`。
2. 浏览器通常会自动打开。如果没有，请打开终端中显示的本地地址（默认是 <http://127.0.0.1:4173>）。
3. 导入 MP3、WAV 或 M4A 音频。
4. 预览效果，并按需要调整嘴型灵敏度和最短张嘴时间。
5. 点击“导出剪映透明 MOV”；处理完成后点击“导出完成，点击保存 MOV”，再把视频导入剪映。

导出文件会自动识别 8 帧 OC 的共同透明边界，保持人物比例，并在四周保留 8px 透明边距。当前素材导出约为 186×208px；人物在最终画布中的位置和大小请直接在剪映中调整。

不需要运行 `npm install`。电脑需要 Node.js 18（最低要求）或更高版本，并随 Node.js 提供 `npm`；Node.js 24.16.0 已测试通过。

电脑还需要已经安装 FFmpeg 和 ffprobe：程序会优先使用 `/opt/homebrew/bin/ffmpeg` 与 `/opt/homebrew/bin/ffprobe`；如果这两个路径不可执行，则从 `PATH` 中查找。

使用结束后，回到启动程序的终端窗口，按 `Control-C` 停止本地服务。
