# PAPAlu 说话中途误进入待机修复设计

## 问题与根因

用户仍在连续说话时，PAPAlu 偶尔闭嘴并显示思考云。思考云只会在基础状态已经变成 `idle` 后出现，因此可以排除窗口动画计时器故障，确认问题来自 `MouthGate` 误判。

当前默认配置在平滑音量低于 `0.015` 达到 `120ms` 后关闭嘴巴，而重新开口要求某个原始音量缓冲达到 `0.025`。自然说话中的短停顿可能超过 120ms；停顿后的轻声又可能低于 0.025，导致人物在一句话中途保持 idle。

真实口播回放也支持这个判断：现有算法在 26.5 秒录音中进入/退出 talking 各 17 次，talking 覆盖 47.1%。

## 最小修复

只调整 `MouthGateConfiguration.default`：

- `openThreshold`: `0.025 → 0.020`
- `releaseDelay`: `0.12s → 0.30s`
- `closeThreshold`: 保持 `0.015`
- `smoothingFactor`: 保持 `0.35`

这样可以跨过约 200ms 的句中短停顿，并让较轻的后半句重新触发 talking。真实录音离线回放下，talking 覆盖提高到 60.0%，进入/退出次数各降为 14 次。

## 不变范围

- 不修改思考云的 0.5 秒出现延迟。
- 不修改 talking 帧、idle 摆动或眨眼。
- 不增加设置 UI、自适应噪声模型或音频保存。
- 真正持续安静超过约 300ms 后仍回到 idle；思考云随后按原规则出现。

## 验证

自动测试覆盖：

- 默认配置采用批准的新参数。
- talking 中约 200ms 的静音不会误关闭。
- 安静超过 300ms 后仍会关闭。
- RMS 为 0.020 的轻声可以从 idle 立即进入 talking。
- 低于 0.020 的背景声不会触发 talking。
- 原生、离线网页和摄像头移除回归测试继续通过。

真人验收重点是连续说话 30 秒，包含轻声、句中停顿和正常换气，确认中途不再出现思考云。
