# PAPAlu Idle 漫画思考云设计

## 目标

在 PAPAlu 停止讲话进入 idle 后，用一个白色漫画思考云表达“正在思考”，进一步增加角色状态的可读性和生命感。

## 视觉

- 思考云位于 PAPAlu 头部右上方。
- 主体由多个白色圆形组合成小云朵，使用细深紫色描边，保证录制白色页面时仍然可见。
- 云朵与头部之间有两个由小到大的白色圆泡，形成漫画思考框连接感。
- 云朵内部有三个深紫色小圆点，按左、中、右顺序轻微明暗变化。
- 不使用文字字符 `...`，避免字体和系统渲染差异。
- 不生成 PNG；全部由 AppKit/Core Animation 绘制。

## 时序

- `talking → idle` 后启动独立的 `0.5s` 显示延迟。
- 延迟结束时，如果仍为 idle，思考云以约 `180ms` 淡入。
- 三个点以约 `0.3s` 一步循环，完整周期约 `0.9s`。
- 重新进入 talking 时立即取消等待、停止点动画并隐藏思考云，不等待当前周期结束。
- 启动 App 时如果保持安静，同样在 idle 约 `0.5s` 后显示。

`MouthGate` 的 120ms release delay 和现有 talking-to-idle 收口序列保持不变；思考云延迟从进入 idle 时开始计算，不额外阻塞 idle 动画。

## 布局与缩放

- 思考云是窗口内容中的独立覆盖层，不放在正在左右轻摆的角色图层里，因此云朵不会随人物一起摇晃。
- 窗口缩放时，云朵的位置、大小、圆点和描边按相同比例调整。
- 思考云不接收鼠标事件，不影响点击人物拖动窗口。
- 保留现有透明窗口边界；优先使用素材顶部和右侧的透明留白，不扩大屏幕占用范围。

## 结构

- 新增纯 Swift `ThoughtCloudPlan`，集中定义出现延迟、点切换间隔、透明度和布局比例，便于测试与后续微调。
- 新增轻量 `ThoughtCloudView`，只负责绘制白色云朵、描边、尾随圆泡和三个圆点。
- `PAPAluWindow` 只负责在 idle/talking 状态切换时启动或取消思考云。
- 不新增第三种业务状态；思考云只是 idle 的视觉附属效果。

## 状态关系

- talking：思考云隐藏，现有嘴型正常运行。
- idle：左右轻摆和随机眨眼照常运行，思考云延迟出现并持续点动画。
- idle → talking：思考云立即隐藏，快速起嘴优先。

## 测试与验收

- 测试默认显示延迟为 `0.5s`，点切换间隔为 `0.3s`。
- 测试点索引按 `0 → 1 → 2 → 0` 循环。
- 测试布局随窗口尺寸等比例缩放，并保持在头部右上方范围内。
- AppKit 壳层测试验证思考云可被注入窗口并随 idle/talking 调度。
- 原 MouthGate、idle、缩放、无摄像头契约和离线网页测试继续通过。
- 真人验收：安静后出现漫画思考云，讲话立即消失，缩放和拖动不受影响，QuickTime 可录到完整云朵。

## 不做

- 不新增 PNG、GIF 或角色帧。
- 不增加文字、字幕、语义识别或更多情绪状态。
- 不恢复摄像头。
- 不增加设置页面或思考云开关。
- 不调整口型、左右轻摆或眨眼参数。
