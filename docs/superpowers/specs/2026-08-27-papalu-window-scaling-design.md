# PAPAlu 实时窗口缩放设计

## 目标

让用户在不同录屏尺寸下快速调整 PAPAlu 大小，同时保持透明悬浮窗口和无控制面板体验。

## 交互

- `Command +`：放大一级。
- `Command -`：缩小一级。
- `Command 0`：恢复默认大小。
- 三个命令同时显示在应用菜单中，录屏画面内不出现按钮或缩放手柄。

## 尺寸规则

- 默认尺寸保持 `288×312`。
- 每级调整 10%。
- 最小 50%，最大 200%。
- 始终保持现有角色素材宽高比。
- 缩放围绕窗口中心进行，避免人物位置突然跳到另一侧。

## 实现边界

- 复用现有 `PAPAluWindow`，不修改或复制角色帧。
- 将缩放档位计算写成可重复测试的纯逻辑。
- `AppDelegate` 只负责把菜单命令转发给窗口。
- 不新增控制面板、右键菜单、触控板手势或 resize 边框。
- 不保存缩放比例；每次启动恢复默认大小。

## 验收

- 连续缩小不会低于 50%。
- 连续放大不会高于 200%。
- 恢复命令回到 `288×312`。
- 缩放后仍可拖动、浮在普通窗口上方并被屏幕录制捕获。
- 实时口型和原离线网页工具测试继续通过。
