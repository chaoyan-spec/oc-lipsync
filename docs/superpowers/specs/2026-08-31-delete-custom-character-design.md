# 删除自定义角色设计

## 目标

允许用户从 macOS 悬浮角色的右键菜单删除当前唯一的自定义角色槽位，同时避免误删用户原始图片。

## 用户流程

1. 已存在自定义角色时，右键菜单显示可用的“删除自定义角色…”。没有自定义角色时，该菜单项置灰。
2. 点击后弹出确认框，明确说明只会删除 App 保存的闭嘴、张嘴副本，不会删除用户最初选择的图片。
3. 用户取消时不做任何改变。
4. 用户确认后，删除 `Application Support/悬浮说话角色/CustomCharacter` 中保存的素材。
5. 如果当前正在使用自定义角色，删除成功后切换到“猫 Meme”；如果正在使用其他角色，则保持当前角色。
6. 菜单继续保留“自定义角色”和“设置自定义角色…”，用户可以重新上传。

## 技术设计

- `CustomCharacterStore` 新增幂等 `delete()`：目录不存在时直接成功，存在时删除整个专属目录。
- `AppDelegate` 新增删除菜单动作、确认弹窗和成功后的 catalog/preferences/menu 同步。
- 只有存储删除成功后才修改内存和当前选择；失败时保留现有角色并显示错误。
- 不删除原始上传路径，不增加废纸篓、历史版本或恢复功能。

## 验证

- 存储测试覆盖：保存后删除、删除后不可加载、重复删除不报错。
- 应用外壳继续编译，现有 41 项功能测试不回归。
- 真人预览覆盖：取消删除、删除非当前自定义角色、删除当前自定义角色、删除后重新上传。

## 非目标

- 本轮不支持多个自定义角色槽位。
- 不修改 Windows 版本。
- 不删除内置猫咪或 PAPAlu。
- 不增加素材管理页面或废纸篓。
