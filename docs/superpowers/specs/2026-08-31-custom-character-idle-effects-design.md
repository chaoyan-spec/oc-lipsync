# 自定义角色待机效果对齐设计

## 目标

让用户导入的闭嘴、张嘴两图角色在安静时不再像静态贴纸，而是复用已经验收的内置猫咪待机体验。

## 行为

- 自定义角色继续使用现有 `IdleMotionConfiguration.gentle`，保持与内置猫咪相同的轻微左右飘动幅度和节奏。
- 安静约 0.5 秒后显示现有思考云，位置、尺寸、三点动画与内置猫咪一致。
- 检测到讲话后立即停止待机飘动、隐藏思考云，并进入现有 8 fps 两图口型节奏。
- 再次安静时重新进入待机飘动并按现有延迟显示思考云。

## 非目标

- 不生成或修改用户角色图片。
- 不给两图角色伪造眨眼、表情或其他动作帧。
- 不增加设置 UI，不提供角色级待机强度调节。
- 不修改 PAPAlu、内置猫咪、麦克风门限或窗口布局。

## 验证

- 自动测试确认自定义角色的待机参数与内置猫咪一致，并启用思考云。
- 原有口型、角色切换、资源和应用外壳测试继续通过。
- 构建最新版 macOS App，启动后用自定义角色完成安静、讲话、再次安静的真人预览。
