# 悬浮说话角色（Windows 10 / 11）

这是 macOS“悬浮说话角色”的轻量 Windows 版。它读取默认麦克风的实时音量，让当前角色在 talking 和 idle 之间切换；音频只在内存中用于计算音量，不会保存、上传或联网。

## 直接使用

1. 解压 `悬浮说话角色-win-x64.zip`，不要直接在压缩包里运行。
2. 双击 `PAPAluLive.Windows.exe`。
3. 对麦克风讲话，确认角色开口；停止讲话约 600ms 后，角色进入轻微待机并显示思考云。
4. 用鼠标左键拖动角色。右键角色可以切换形象、导入或删除自己的角色、缩放或退出。

内置角色包括猫 Meme、Huh 猫、Happy 猫、抱头尖叫猫和 PAPAlu。自定义角色需要两张 PNG：一张闭嘴、一张张嘴。图片尺寸可以不同，程序会自动放进同一画布、底部对齐并居中，不会拉伸或裁切；透明背景效果最好。

角色选择、位置和缩放保存在 `%LOCALAPPDATA%\PAPAluLive\settings.json`，自定义图片的 App 副本保存在同一目录下的 `CustomCharacter` 文件夹。右键删除自定义角色只会删除这些副本，不会删除最初选择的 PNG。

## 麦克风没有反应

进入“设置 → 隐私和安全性 → 麦克风”，打开：

- 麦克风访问权限
- 允许应用访问麦克风
- 允许桌面应用访问麦克风

然后完全退出并重新打开应用。本版固定使用 Windows 当前的默认输入设备，不提供设备选择器。

## 录制教程

推荐使用 OBS 的“显示器采集”，再选择同一个麦克风作为音频输入。悬浮角色是一个独立窗口，因此不保证 OBS 的“窗口采集”能够把教程应用和角色同时录进去。

正式录制前先录 10 秒短片，检查：屏幕、声音、透明角色是否同时出现。如果 Windows SmartScreen 提示未识别应用，这是因为当前验收包尚未签名；选择“更多信息 → 仍要运行”即可继续本机测试。

## 当前边界

- 支持 Windows 11 x64；Windows 10 22H2 x64作为兼容目标验收。
- 只支持一个当前角色。
- 不做语音识别、音素级口型、摄像头、动作捕捉或音频保存。
- 没有麦克风设备选择器，切换设备请先修改 Windows 默认输入设备并重启应用。
- 当前验收包未签名、未公证、未上架 Microsoft Store。

## 在 Windows 上构建

安装 .NET 10 SDK，在仓库根目录打开 PowerShell：

```powershell
.\realtime-windows\build-windows.ps1
```

脚本会运行核心测试和 Windows 图像冒烟测试，再生成自包含的 x64 压缩包：

`outputs\windows\悬浮说话角色-win-x64.zip`

最终用户不需要单独安装 .NET。
